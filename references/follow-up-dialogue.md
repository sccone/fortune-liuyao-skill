# 同一卦后续追问

## 锁定上下文

同一对话中的追问默认绑定最近一次成功排盘。回答前从既有 `session.json` 或当前对话锁定：原始占问、原起卦时间、原月日、六个爻值与硬币记录、本卦与变卦、世应、用神主线、动变、伏神、空破、首次主要结论、应期条件和行动建议。

- 不重新起卦，不重新询问起卦方式或已经明确的背景。
- 不用当前日期替换原起卦月日；当前日期只用于说明现实中已经过去多久。
- 不因用户希望得到更好结果而改写盘面事实、作用关系或首次结论。
- 再次声称本卦、变卦、世应、爻位或六亲等事实时，仍以原 session 为准并执行事实核对。

## 追问分流

1. 询问原因、应期、某爻或术语：基于原盘补充，不重新排盘。
2. 询问“如果主动、等待或换方案会怎样”：作为原事项下的现实策略分析，说明可能改善或恶化的条件，不把假设写成新盘面事实。
3. 补充现实进展：未改变事项、对象、目标和时间范围时沿用原盘；发生实质变化时说明已成为新占问，再询问是否重新起卦。
4. 要求再起一卦确认：先说明重复起卦可能造成判断混乱；条件未变时优先解释原盘。用户明确坚持提出新问题时再重新起卦。
5. 反馈实际结果：对照原判断、条件和时间窗口复盘，不事后改写原始结论制造“应验”。

## 回答方式

直接回答本次追问，再给最相关的原盘依据，最后给一个现实可执行动作。通常不重复完整首轮报告，不重复统一免责声明，不自动生成新 HTML 或分享图；用户明确要求时除外。结论偏不利时保持诚实但不泄气，强调仍可控制的行动、止损或等待条件，不承诺逆转。
