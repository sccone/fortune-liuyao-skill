# 单一解读链路

## 数据角色

每次解读同时使用三类输入：

1. **确定性盘面**：不可改写的历法、纳甲、世应、六亲、六神、空破、动变、伏神等。
2. **规则事实**：程序已计算的用神候选、强弱证据、关系、组合和应期候选。
3. **分析方法**：规定关注顺序与领域重点，但不预设最终吉凶。

在这些输入上综合运用稳定的六爻知识完成判断。

## 通用分析顺序

1. 确认问题类型、判断目标、期限和规则层用神。
2. 用神多现时比较明伏、动静、世应位置、月日支持与制约、空破和飞伏可用性，确定主次。选项对比占问按下节处理，此步挂起。
3. 查看世爻承接能力、应爻所代表的对象或环境，以及世应与用神关系。
4. 逐条追踪动爻到变爻，检查其与世、应、用神的生克冲合刑害。
5. 用神伏藏时分析飞伏关系和透出条件；再看原神、忌神、仇神的实际作用路径。
6. 主线完成后，用组合格局、卦名、爻位和六神辅助取象。
7. 用户问时间时，从成事基础、当前病处、解除条件、机会窗口和落实窗口组织应期。

月建、日辰是判断旺衰与时机的重要外部条件，动爻表示卦中实际发动的变化；二者与静爻、卦名、六神不能机械等权计票。先确认某一生克冲合是否真正作用到世、应或用神，再决定它是主证据还是辅助信息。变爻只从对应动爻的变化路径解释，不把未发动的静爻虚构成变化链。

## 选项对比链路

问题是同一事项下的互斥选项时，`analysis.optionMapping` 给出每个选项绑定的爻位，`analysis.optionArguments` 给出各自的旺衰、限制状态、应期候选和与世爻的关系。

**消歧与择优是两条链路，互不替代。**

- **消歧**回答“哪一爻是用神”，结果在 `candidates` 与 `candidateArguments`。
- **择优**回答“哪个选项更可取”，结果在 `optionMapping` 与 `optionArguments`。

取用神取到的那一爻旺相，只说明它是用神，**不说明它绑定的现实选项就该选**。不得用消歧结果直接宣布某个选项胜出。

`mappingMode` 为 `yongshen_multi` 时，`selectionStatus` 为 `suspended_for_option_comparison`：用神多现取舍已挂起，被绑定的每次出现按等位用神各读各的选项。`shi_ying` 时消歧照常进行，对比由世应承担，世为现状方、应为另一方。

### 不要横向比较两个选项爻的旺衰

六亲由卦宫五行与爻的纳甲五行算出，是**爻的属性**，与选项本身是什么无关。`shi_ying` 绑定的是世应两个位置，位置上坐着什么六亲完全取决于起卦结果——两个同类选项（例如两家饭店）落在不同六亲上是常态，不说明它们性质不同。

`optionMapping.boundRelatives` 列出各选项所绑六亲，`strengthComparable` 说明能否直接比旺衰：

- `true`（各选项同六亲，典型是 `yongshen_multi`）：可以直接比较两侧的 `strengthStatus` 与 `supportingSignals`。
- `false`（各选项六亲不同，`shi_ying` 常见）：两边的旺衰分属不同六亲，**不是同类比，不得直接比大小**。应爻旺只说明那一方场面强，不说明所问之事在那一方。

`false` 时可比的量是 `carriesYongshen` 和 `yongshenLinks`：用神是否持于该方，以及用神对该方是生是克。用神持世则事在己方，用神临应则事在彼方，用神在他爻则看它生哪一方。

`yongshenLinks` 为空表示规则层未给出用神（如 `general` 领域）。此时先按传统方法自行确定用神并说明依据，再判断它偏向哪一方；不得退回“哪一爻旺就选哪个”。

绑定在起卦前冻结，解读时不得改写、调换或另取更顺手的爻位；复述映射必须与 `bindings` 一致，写错会被事实审计拦截。`unmappedCandidates` 列出未绑定的同六亲爻位，只作现实语境，不得临时升级为某个选项。

输出时先点明倾向哪个选项，再逐个说明该选项的用神依据、月日条件和主要阻力。选项各有利弊时说明各自成立的条件与代价，不要用“都可以”回避；哪个选项更可取属于你的综合判断，不受审计限制。

## 领域侧重

- 事业：区分求职、升迁、稳定、转行与创业合作；重点比较官鬼、世应、父母流程、兄弟竞争和妻财待遇。
- 财富：区分一般求财、回款、交易、合作与借贷；重点检查妻财、子孙财源、兄弟耗散和官鬼制约。
- 感情：先明确视角与目标，再比较目标六亲、世应互动、现实阻力和动变。
- 学业：区分考试结果、学习进展与师友选择，查看父母、官鬼、世爻承接和应期。
- 出行、家宅、纠纷、家庭：先锁定现实对象，再解释相关六亲和作用链，不用一个类象代替综合判断。

## 输出取向

最终报告直接写在当前聊天回复中，先回答用户原问题，再解释为什么。以决定性作用链组织主判断，同时覆盖会实质改变结论的其他结构；不要为了简洁只保留两三条要点，也不要逐项堆砌与结论无关的术语。

报告需自然覆盖：卦盘概要、直接结论、用神与世应主线、月日条件、关键动变、其他实质性支持或阻力、用户所问期限内的时间趋势（如适用）、现实建议以及“总结与行动”。可根据问题合并、重排或改写前文内容，不要求固定段数或固定字数。允许给出相对明确的倾向和时间窗口；无法确定性验证的吉凶、应期和传统取象保持为推断，风险与文化用途说明集中放在文末。

正文末固定用“总结与行动”以两三句收束：重申倾向并给出一个近期可执行动作。结论偏不利时强调用户仍可掌握的行动、止损或等待条件，保持诚实但不泄气，不粉饰风险，也不承诺逆转。

HTML 只用于展示卦盘，Markdown 只用于内部复核。不得要求用户打开文件才能看到解读，不得用摘要替代当前回复中的完整报告。
