# 交互与展示契约

默认使用宿主 Agent 对话界面，不启动额外网页服务。交互顺序固定为：

**读取问题 → 自动识别问题上下文 → 选择起卦方式 → 确定性起卦排盘 → 返回 `result + prompt` → 当前 Agent 解读 → 事实审计并生成最终 HTML。**

选择起卦方式时立即使用宿主的单选控件；不支持时降级为一条简短文字。只询问自动、逐爻弹窗、硬币/爻值三种方式，不输出清晰度、敏感分流或领域路由的内部判断。用户选定后立即执行。

用户选择“硬币／爻值”后，立即主动说明：系统不识别硬币图案，默认把面额数字／文字面记为正、国徽或花卉等图案面记为反，并在六次中保持一致；正面记 3、反面记 2；6=老阴动、7=少阳、8=少阴、9=老阳动；第一次为初爻、第六次为上爻。随后要求用户一次性反馈六轮正反组合，并备注 `正=字／面额面，反=国徽／花卉面`；也可收取六个爻值。用户已经随选择直接提供完整输入时不重复说明。

“逐爻弹窗”固定使用六次宿主选择控件串联：第一次显示“生成初爻”；用户点击后运行 `cast_one_line.py --position 1`，保存结果，并立即在下一弹窗显示初爻结果和“生成二爻”。依次执行至上爻。弹窗之间不输出说明文字，不做领域分析、盘面判断或阶段总结；只保存当前结果并立即调用下一弹窗。每个位置只生成一次，不得重新运行已经完成的位置。第六爻生成后不再询问确认，直接把六个值按初爻至上爻交给统一入口排盘。

宿主弹窗每次提交都会恢复一次 Agent 执行，可能有短暂等待；不得通过重摇全部六爻或改成文字确认来“加速”。若宿主不支持选择控件，改为一次输入六轮硬币／爻值，不模拟六轮文字对话。

聊天中的完整文字解读是每次成功排盘的必需交付；最终 HTML 是同一份报告的可保存副本；宿主具备图片能力时再生成标准分享图：

- 统一入口先从同一份排盘生成临时卦盘 HTML 和内部 Markdown；此时不要交付临时 HTML；
- 当前 Agent 写完完整解读后，调用 `render_final_report.py` 进行事实审计并把解读合并进最终 HTML；
- 支持 HTML 文件时，只将最终 HTML 作为文件链接或附件返回；禁止把 HTML 源码直接粘贴到回答中；
- 不向用户展示或附加 Markdown 文件，不要求用户借助文件预览器查看解读；
- 无论是否附加 HTML，都直接在聊天回复中输出完整文字解读；HTML 的状态不得影响正文内容和完整度；
- 不要声称网页已经打开，除非当前环境确实返回了可访问的 HTML 文件。
- 分享图固定为 1080 × 1440 PNG，并遵循 [share-card-contract.md](share-card-contract.md)；它只承载盘面摘要，不能代替完整报告。优先使用宿主图片能力；没有图片模型但有浏览器截图能力时，从同一份确定性 HTML 渲染；两者都没有时只交付 HTML。
- 分享图生成失败时只省略图片，不得缩短聊天解读或阻断最终 HTML。

最终 HTML 生成失败、宿主不能返回附件或用户无法打开时，只放弃附件；不调用代码编辑器打开 HTML，不反复尝试桌面启动命令，也不改为交付 Markdown。聊天中的完整文字解读始终照常输出，它不是 HTML 失败后的降级方案。

必须先显示本卦、变卦及对应六爻图，再显示解读。解读失败时保留盘面。

选项对比占问额外要求：卦盘区必须显示取用格式、每个选项的标签及其绑定爻位，被绑定的爻行标出对应选项。没有这些字段，读者无法核对解读里的映射是否属实，HTML 就不能自证。这些字段由同一份排盘生成，不得手工补写或改动。

选择起卦方式前若问题是互斥选项，先按 [domain-routing.md](domain-routing.md) 声明选项与取用格式，再进入起卦方式选择；不要先起卦再补声明。向用户确认选项时只问选项本身，不输出取用格式、绑定爻位等内部判断。

起卦由 Agent 对话或 `cast_lines.py` 完成。自动起卦使用 `python_secrets`，手动硬币结果保留原始六轮记录和正反面换算约定。

三种起卦方式均保留初爻至上爻顺序和原始审计记录。Skill 不访问模型 API；当前 Agent 直接使用统一入口返回的 `prompt`。盘面展示完成后必须在当前对话继续输出完整报告，不得把卦盘、附件、一段临时摘要或“详情见文件”当作最终答案。敏感放行、路由结果、脚本状态和校验通过均保持静默。

## 语言

盘面数据本身没有语言：`chart` 里的六亲、纳甲、六神、卦名都是这套体系的记号，中文就是它们的原形。英文界面不该自己翻译它们——一份自带的译表迟早会和引擎对不上，而且第二个客户端还要再写一份。

改用 `lexicon.chart_lexicon(result, language)`：它只返回**这张盘里出现过的**值的译法，一个扁平的 `中文 → 英文` 表。客户端把拿到的任何值往表里查，查不到就原样显示。中文时返回空表，因为中文不需要翻译。

卦名译成「Water over Thunder - Zhun (Difficulty at the Beginning)」这样的三段式：上下卦象、King Wen 名的拼音、通行英译。八纯卦写成「Water Doubled - Kan」。纳甲写成 `Geng-Xu`——它是六十循环里的一个坐标，不是词，译成动物只会让读者以为盘里有只狗。

一次解读只有一种语言。起卦时选的语言决定这次的盘面标签和解读正文；之后改设置只影响下一卦，不回头重排已经生成的那一份。解读文本本来也翻不回去，让标签跟着正文走才是对的。
